# 阪大シャトル / handai-shuttle

大阪大学の豊中・箕面・吹田キャンパス間を走る学内連絡バスを、スマートフォンから検索しやすくする**非公式Webアプリ**です。

> [!IMPORTANT]
> 本アプリは大阪大学公式サービスではありません。運行可否・臨時運休・利用条件は、大阪大学公式「学内連絡バス」の案内を正本としてください。

## 主な機能

- 現在時刻から次に乗れる便を表示
- 豊中・箕面・吹田間の出発／到着時刻検索
- 吹田の工学部前・人間科学部前を考慮した位置情報推定
- 直行／箕面経由の区別
- 往復検索と滞在時間指定
- キャンパス・行先別の時刻表
- 最終便・残り本数の表示
- iPhone向けのモバイルUI

## データ

2026年4月1日改正の大阪大学公式時刻表を基にしています。

- 公式案内: https://www.osaka-u.ac.jp/ja/access/bus
- 道路・気象状況による遅延、臨時運休、車両位置、満席状況は反映しません。

## 位置情報

位置情報はブラウザ内で現在キャンパス・吹田停留所を推定するためだけに使用します。位置情報を本アプリのサーバーへ送信・保存するバックエンドはありません。

## 開発

静的HTML/CSS/JavaScriptで構成しています。検索ロジックのテストはNode.jsで実行できます。

```bash
node --check src/search-engine.mjs
node --check src/app.mjs
node --check src/enhancements.mjs
node --check src/features-v3.mjs
node --test tests/*.test.mjs
```
