# 広告クリエイティブ配置 v2 — Yahoo!乗換案内参考

## 目的

阪大シャトルの自社広告を、経路検索の主目的を邪魔せず、かつUI幅・ブランド表現を崩さない形で配置する。

## Yahoo!乗換案内スクリーンショットから採用した配置原則

1. 検索UIの主要操作を完了した後に広告を見せる。
2. 時刻表ではヘッダー/selectorと便一覧の境界に広告を置く。
3. 長い検索結果・時刻表では、数件おきに独立した広告を挟める。
4. 広告は便カードへ擬態させず、`自社広告`/`広告`を明示する。
5. 通常フィードでは横長、検索トップのみ300×250系に近い大型広告を許容する。

## 阪大シャトルでの配置

### Home
`次の便` → `行き先` → `検索CTA` の後、`このあとの便`より前にcompact広告を1枠。

### Search
- 検索フォームをコンパクト化し、その直後に600×500 SVGの大型主広告を1枠。
- 日時指定・詳細検索条件はBottom Sheetへ移し、大型広告が初期画面に入りやすい高さへ抑える。
- 長い検索結果では4件ごとに横長compact広告を追加し、最大2枠まで。
- 1本前/1本後などの高頻度操作の直近には配置しない。

### Timetable
- 640×89の横長広告をキャンパス/行先/乗り場selectorの**上**に配置。
- 広告自体をtopbar直下でstickyにし、selectorは広告の直下でstickyにする。
- sticky広告領域とselector領域は完全な白背景とし、背後の便カードを透過させない。
- 長い時刻表では8便ごとにcompact広告を追加し、最大2枠まで。

## クリエイティブ

- Compact: `assets/ads/house/v2/house-banner-simple-640x89.webp`
- Search primary: `assets/ads/house/v2/house-rectangle-600x500.svg`

Search primary SVGは現行のブランドマークのベクター形状と現行UIパレットを使用する。大型表示でもラスター拡大によるロゴ破綻を起こさない。

## 寸法・角丸ルール

- 広告slotは周囲の便カード/検索フォームと同じ利用可能幅を使う。
- `max-width: 320px/360px` のような広告固有の縮小制限は設けない。
- 横長クリエイティブ自体に完成済みの角丸・枠線があるため、外側buttonでは追加clipしない。
- CSS側は `object-fit: contain` を固定し、トリミングを禁止する。
- 画像本体と外側containerで二重の角丸を作らない。

## UXガードレール

- 次便Heroには入れない。
- 検索フォーム内部には広告を入れない。
- Bottom Sheetには入れない。
- bottom navigationには重ねない。
- 便カードに見せるNative風実装は禁止。
- Vignette OFFを初期方針とする。
- 大型広告はSearchの主広告1枠のみ。inlineはcompact creativeを使う。
- 画像は比率を保ち、実行時トリミングしない。

## 将来のGoogle広告への置換

`AD_PLACEMENTS`を維持し、`house` providerを`adsense` providerへ差し替える。検索・時刻表の位置ロジックは変更しない。
