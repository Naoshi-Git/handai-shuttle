# 広告クリエイティブ配置 v2 — Yahoo!乗換案内参考

## 目的

ユーザー提供の高品質な阪大シャトル自社広告クリエイティブを、経路検索の主目的を邪魔しない位置へ実際に差し込む。

## Yahoo!乗換案内スクリーンショットから採用した配置原則

提供された参考画像では、広告は主に以下に配置されている。

1. **検索UIの直後 / 検索結果の直前**
   - 検索操作が完了してから目に入る。
   - 検索フォームや検索ボタンそのものには広告を重ねない。
2. **時刻表詳細のヘッダー直下 / 時刻表リストの直前**
   - 時刻表の行に擬態させず、独立した横長広告として分離。
3. **検索結果の先頭または結果の区切り**
   - 経路カードと同じ見た目にはしない。
4. **広告ラベルを右上に明示**
   - コンテンツとの誤認を避ける。
5. **横長クリエイティブを中心に使用**
   - モバイルで縦方向を過剰に消費しない。

## 阪大シャトルでの配置

### Home
`次の便` → `行き先` → `検索CTA` の操作を終えた**直後**、`このあとの便`より前に1枠。

### Search
検索結果リストの**先頭**に1枠。検索フォーム内部・前後便ボタン付近には入れない。

### Timetable
stickyのキャンパス/行先/乗り場selectorの後、**最初の時刻表行より前**に1枠。

## クリエイティブ

- Home / Timetable:
  - `house-banner-simple-640x89.webp`
  - 元のユーザー提供1536px広告から広告本体だけを安全領域込みでクロップ。
- Search:
  - `house-banner-feature-640x213.webp`
  - ユーザー提供1536×512クリエイティブを640×213へ高品質縮小。

両方とも、CSS側で`object-fit: contain`を使い、トリミングを禁止する。

## UXガードレール

- 次便Heroには入れない。
- 検索フォームには入れない。
- Bottom Sheetには入れない。
- sticky selectorとbottom navigationには重ねない。
- 便カードと同じ白カードに見せない。
- 1画面に同時に複数の大広告を見せない。
- 画像は拡大しない。親幅に合わせて縮小のみ。
- 広告ラベルは右上へ小さく固定し、クリエイティブの本文とは分離する。

## 将来のGoogle広告への置換

同じ`AD_PLACEMENTS`を維持し、`house` providerを`adsense` providerへ差し替える。位置ロジックは変更しない。
