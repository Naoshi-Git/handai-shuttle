# 広告クリエイティブ配置 v2 — Yahoo!乗換案内参考

## 目的

ユーザー提供の高品質な阪大シャトル自社広告クリエイティブを、経路検索の主目的を邪魔しない位置へ実際に差し込む。

## Yahoo!乗換案内スクリーンショットから採用した配置原則

1. 検索UIの主要操作を完了した後に広告を見せる。
2. 時刻表ではヘッダー/selectorと便一覧の境界に横長広告を置く。
3. 長い検索結果・時刻表では、数件おきに独立した広告を挟める。
4. 広告は便カードへ擬態させず、`自社広告`/`広告`を明示する。
5. モバイルでは横長クリエイティブを中心に使い、縦方向を占有しすぎない。

## 阪大シャトルでの配置

### Home
`次の便` → `行き先` → `検索CTA` の後、`このあとの便`より前に1枠。

### Search
- 検索フォームをコンパクト化し、その直後に640×213の主広告を1枠。
- 日時指定・詳細検索条件はBottom Sheetへ移し、広告が初期画面内に入りやすい高さへ抑える。
- 長い検索結果では4件ごとに細い広告を追加し、最大2枠まで。
- 1本前/1本後などの高頻度操作の直近には配置しない。

### Timetable
- 640×89の横長広告をキャンパス/行先/乗り場selectorの**上**に配置。
- 広告自体もtopbar直下でstickyにし、selectorは広告の直下でstickyにする。
- 長い時刻表では8便ごとに細い広告を追加し、最大2枠まで。
- 便行と同じデザインにはしない。

## クリエイティブ

- Compact: `assets/ads/house/v2/house-banner-simple-640x89.webp`
- Feature: `assets/ads/house/v2/house-banner-feature-640x213.webp`

CSSは`object-fit: contain`を固定し、実行時トリミングを禁止する。

## UXガードレール

- 次便Heroには入れない。
- 検索フォーム内部には広告を入れない。
- Bottom Sheetには入れない。
- bottom navigationには重ねない。
- 便カードに見せるNative風実装は禁止。
- Vignette OFFを初期方針とする。
- 大型広告はSearchの主広告1枠のみ。inlineはcompact creativeを使う。
- 画像は拡大・トリミングせず、比率を保った縮小のみ。

## 将来のGoogle広告への置換

`AD_PLACEMENTS`を維持し、`house` providerを`adsense` providerへ差し替える。検索・時刻表の位置ロジックは変更しない。
