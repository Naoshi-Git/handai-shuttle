USE CASES

使う場面が、すぐ浮かぶ。

左右にスワイプして、よくあるキャンパス移動を見てみてください。

01

「10:30の授業に、何時の便なら間に合う？」

他キャンパスの授業

到着したい時刻を指定して、間に合う便を逆算。出発時刻を自分で計算する必要はありません。

到着時刻検索
02

「4限が終わった。18時の豊中集合、どれに乗る？」

サークル・部活

次の便と所要時間を確認して、その便を共有。集合前のやり取りまで短くできます。

次の便・共有
03

「今から吹田へ行くなら、次はいつ？」

研究室・ゼミ

普段は使わないキャンパスへの移動でも、現在地から次に乗れる便だけをすぐ確認できます。

現在地から検索
04

「箕面から、豊中と吹田のどちらへ行く？」

箕面からの移動

キャンパスと行先を選ぶだけ。豊中方面・吹田方面を、同じ操作感で見比べられます。

行先別時刻表
05

往復の短時間移動
